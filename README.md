# 태블릿 로컬 차량 정비관리 프로젝트

갤럭시탭에서 차량 운용·정비 기록을 관리하고, 합성 데이터로 학습한 모델을 기기 안에서 실행하는 Flutter Android 앱 개발 프로젝트입니다. 로그인 없이 사용하며 운영 중 인터넷이나 별도 서버를 이용하지 않습니다.

이 저장소에는 **공개용 개발 현황 문서**를 정리했습니다. 아래 결과는 로컬 개발 작업물을 기준으로 합니다. 현재 공개 커밋에는 앱 소스, 데이터 파일, 모델 파일, 디자인 자산과 APK가 포함되지 않으므로 저장소 복제만으로 앱을 실행할 수는 없습니다.

## 기술 스택

- Flutter / Dart: 한국어 태블릿 화면과 Android 앱.
- Riverpod / go_router: 상태 관리와 화면 이동.
- Drift / SQLite: 기기 내부 데이터 저장과 조회.
- Camera / 앱 내부 파일 저장: 촬영과 점검 원본 보관.
- Python / NumPy: 개발 PC에서 합성 데이터 모델 학습.
- Dart / JSON 모델: 태블릿에서 서버나 Python 없이 추론.

## 최근 학습·검증 결과

| 예측 평가 | ROC-AUC | F1 | 시험 표본 |
| --- | ---: | ---: | ---: |
| 기존 합성 데이터 v2 | 0.630 | 0.287 | 3,600 |
| 개선한 합성 데이터 v3 | 0.884 | 0.515 | 3,600 |
| v3 미학습 차량의 미래 기록 | 0.884 | 0.564 | 675 |
| v3 거리·유류 입력 오차 | 0.814 | 0.397 | 3,600 |

자동 테스트 15개 통과, 정적 분석에서 문제 없음, 개발용 Android APK 빌드를 확인했습니다. 입력 후 예측 갱신은 PC 단독 테스트에서 약 36~40ms였습니다. 이 시간은 갤럭시탭의 화면 표시 지연이나 카메라 성능 측정값이 아닙니다.

위 점수는 **합성 데이터 생성 규칙에 대한 학습 결과**입니다. v2와 v3는 생성 방식이 달라 동일한 고정 자료에서의 모델 성능 향상으로 해석할 수 없습니다. 실제 차량 고장, 안전 상태 또는 현장 정비 판단의 정확도를 입증하지 않습니다.

## 공개 범위

일반적인 기능, 기술 구성, 완전 가상 데이터의 규모 및 평가 결과만 포함합니다. 원본 업무 자료와 그 집계 정보, 실제 식별자·기록, 기관·조직 식별 정보, 사진, 개인 PC 경로, 비공개 디자인 링크와 인증정보는 포함하지 않습니다.

모델은 자동 재학습·다운로드하지 않으며 사용자 기록과 사진을 외부로 전송하지 않습니다. 문서의 데이터 수치와 시나리오는 실제 운용 현황을 나타내지 않습니다.

# 검증 결과와 남은 작업

## 자동 검증

최종 Flutter 테스트 23개가 통과했습니다.

| 범위 | 검증 |
| --- | --- |
| 화면 흐름 | 로그인 없는 진입·검색·정비 등록·분석 이력 |
| 분류 | 입력 중 제안, 사용자 적용과 저장 |
| 대량 목록 | 12건 페이지, 다음 페이지의 올바른 상세 |
| 화면 배치 | 1280×960, 1280×800, 800×1280, 600×800 및 기준 이미지 |
| ID | 같은 시각에 10,000개 생성해 고유성 검사 |
| 동시 입력 | 차량별 갱신, 미분석 전환, 오래된 확률 방지 |
| 모델 | Python/Dart 추론·특성 일치, 미래 정보 제외 |
| 실시간 반영 | 알림·특성·확률·이력, 연속 10회 입력, 재실행 중복 방지 |
| 이전 데이터 | DB 보존, 초기 목업 중복 방지, 입력 차량 보호 |
| 저장 유지 | 정비·운용·질문·메모·사진 원본 재실행 유지 |
| 기록 관리·백업 | 수정·삭제·변경 이력, 사진 포함 왕복, 손상 파일 거부, DB/예측 실패 롤백, 확인·취소 화면 |
| 입력·학습 자료 | 누적값 감소 거부, 합성 출처·분할·정답 검사 |

별도로 파일 해시·특성·미래 정답 재계산과 동일 시드 재생성 비교를 수행했습니다. 자동 검증은 실제 현장 검증을 대체하지 않습니다.

## 분석 및 APK

- 정적 분석: 문제 없음.
- 개발용 Android APK: 빌드 성공.
- APK 모델 2개·앱 초기 데이터: 최신 파일과 바이트 일치.
- APK 인터넷·네트워크 상태 권한: 없음 확인.
- 배포 전용 서명: 미설정. 현재 빌드는 개발·확인용.

## 로컬 갱신 시간

아래 값은 모델 연동 단계에서 다른 검사·빌드 완료 후 Windows PC에서 단독 측정한 기록입니다. 새 백업·복원의 처리 시간을 측정한 값은 아닙니다.

| 측정 | 시간 |
| --- | ---: |
| 정비 저장 → 예측 갱신 | 약 40.2ms |
| 운용 저장 → 예측 갱신 | 약 35.6ms |
| 연속 10회 P50 | 약 33.7ms |
| 연속 10회 P95 | 약 38.3ms |

저장부터 계산·상태 알림까지의 테스트 시간으로 화면 전체 지연이나 갤럭시탭 성능이 아닙니다. PC 부하에 따라 달라집니다. 새 예측이 화면에 표시되는 동작은 별도 위젯 테스트로 확인했습니다.

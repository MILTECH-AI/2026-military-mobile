# 2026-11-03 남은 화면 비교 실패 해결

갱신 옵션 없이 전체 Flutter 테스트를 실행해 **132개 모두 통과, 실패 0개**를 확인했다. 이전에 남아 있던 22개 화면 비교 실패도 포함한다. 정적 분석은 오류·경고 없이 기존 info 3건만 남았다.

## 원인 확인과 개선

기존 기준 이미지와 현재 macOS 렌더링을 29쌍 모두 나란히 확인했다. 이미지 크기와 화면 배치·줄바꿈·입력·버튼 위치는 유지됐다. 서로 다른 네이티브 글자·아이콘 렌더링으로 경계 픽셀에 1.69~5.97% 차이가 발생했다. 단색 3×3 영역 내부의 색 변경은 모든 이미지에서 0개였다. 수치 검사는 시각 검토의 보조 근거로 사용했다.

`test/flutter_test_config.dart`와 `test/support/host_golden_comparator.dart`에서 실행 ABI에 맞는 기준을 선택하도록 했다. macOS ARM64 기준 29개를 `test/goldens/macos_arm64/`에 추가했다. 기존 공통 경로의 29개 파일은 원본 바이트 그대로 보존했고 Windows x64 실행 경로로 유지했다. 다른 ABI에서 검토된 기준이 없으면 일반 비교는 실패한다.

일반 비교는 Flutter의 엄격한 `LocalFileComparator`를 그대로 사용한다. 허용 오차를 추가하거나 실패를 건너뛰거나 누락 기준을 자동 생성하지 않는다. 새 회귀 검사에서는 1×1 이미지의 한 픽셀을 바꾸어 비교가 실패하고, 이후 원래 픽셀은 여전히 통과하는지 확인했다. 전역 비교 설정이 실제 테스트 실행 시점에도 적용되는지도 검사한다.

후보 생성은 별도 단계에서 수행했고 29쌍을 검토했다. 최종 통과는 `--update-goldens`가 없는 일반 명령으로 확인했다. SDK·엔진·폰트 정보는 `test/goldens/macos_arm64/environment.json`, 재검증과 기준 갱신 규칙은 `test/goldens/README.md`에 기록했다.

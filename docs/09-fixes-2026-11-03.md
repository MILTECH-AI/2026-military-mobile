# 2026-11-03 오류 수정 및 재검증

후속 결과: 남아 있던 22개 화면 비교 실패를 해결해 전체 132개 일반 테스트가 통과했다. 최신 결과와 기준 이미지 검토 내역은 [화면 비교 실패 해결](10-golden-tests-2026-11-03.md)을 따른다. 아래 내용은 이전 수정 단계의 기록이다.

날짜 계산·자정 갱신·카메라 권한 재요청을 수정하고 SM-T735N의 앱을 데이터 보존 업데이트했다. 모델 테스트의 누락 입력·출력 폴더 문제도 수정했다. 전체 자동 테스트가 모두 통과한 것은 아니며, 기존 화면 기준 이미지 비교 22건은 남아 있다.

## 변경 사항

| 문제 | 수정 |
| --- | --- |
| 서머타임 전환 후 예정일이 전날 23시가 됨 | 정비 예정일을 달력 날짜로 구성하고 관측일·최근 기록의 일수도 달력 기준으로 계산 |
| 예측 특성의 경과일이 Python 기준보다 하루 적음 | 공통 `calendarDaysBetween`을 도입해 정비 경과일·최근 90일 특성과 기간 주기 잔여일도 동일 기준 적용 |
| 자정 경과 후 날짜가 전날에 머묾 | 다음 현지 자정의 타이머와 앱 복귀 시 UI 날짜 provider 갱신, 타이머·관찰자 해제 처리 |
| 카메라 권한을 거부하자 바로 다시 물음 | 초기화를 한 번만 실행하고 권한 창의 일시적 inactive에서 진행 중 요청을 유지. 기존에 열렸던 카메라만 복귀 시 자동 재연결 |
| 모델 테스트가 Git 제외 파일에 의존 | `test/fixtures/local_model_parity.json`에 합성 검증 자료 포함, 모델 버전 일치도 검사 |
| 테스트 보고서 출력 실패·운영체제 오표기 | 부모 폴더 자동 생성, 실제 운영체제 표기 |

합성 fixture는 `tools/prepare_model_test_fixtures.py`로 **기존 저장 모델을 읽어** 생성했다. 모델 재학습·가중치 변경은 하지 않았다. 모델을 의도적으로 변경할 때는 Python 도구 의존성 준비 후 프로젝트 루트에서 `python tools/prepare_model_test_fixtures.py`로 재생성하고 차이를 검토한다. 일반 `flutter test` 실행에는 생성 도구 실행이 필요 없다.

## 자동 검증

| 검사 | 결과 |
| --- | --- |
| LA 시간대 전체 Flutter 테스트 | 131개 중 109개 통과, 22개 실패 |
| 한국 시간대 관련 회귀 테스트 | 19개 모두 통과 |
| Python 도구 테스트 | 7개 모두 통과 |
| 정적 분석 | 오류 0, 경고 0, 기존 info 3 |
| 수정 APK 빌드·최종 권한 검사 | 통과 |

새 회귀 검사는 자정·백그라운드 날짜 갱신, 서머타임 시작/종료의 일수, 7일 관측 조건, 권한 요청 중 inactive/resumed와 거부 복귀, 명시적 재시도를 검사한다. 기존 Python/Dart 예측·분류·특성 일치 검사도 LA 시간대에서 통과했다.

남은 실패 22개는 최초 QA에서 실패한 화면 비교 테스트 목록과 정확히 일치한다. 화면 기준 이미지는 수정하거나 비교를 끄지 않았다. 서로 다른 렌더링 환경의 차이 가능성과 실제 화면 변경을 구분해 별도 검토해야 하며, 전체 테스트 통과로 보고하지 않는다. 사진 백업·복원과 선택 AI의 실기기 성능도 아직 완료 판정하지 않는다.

## 수정 앱의 태블릿 확인

- `adb install -r -t` 업데이트 성공. 앱 삭제나 데이터 초기화 없이 기존 QA 차량 `QA-TABLET-1103`, 20,000km / 500H / 1,000L 및 정비 1회를 목록에서 확인했다.
- 카메라 첫 권한 창에서 **한 번 거부**한 뒤 수동 점검 화면으로 전환됐고 추가 권한 창이 나타나지 않았다.
- ‘카메라 사용 조건 다시 확인’을 명시적으로 누른 뒤에만 권한 창이 다시 나왔다.
- ‘이번만 허용’을 선택한 뒤 카메라 미리보기가 열렸다. 앱을 홈으로 보냈다가 복귀한 뒤에도 미리보기가 복구됐다.
- 실제 셔터·사진 저장은 수행하지 않았다. 미리보기 이미지를 별도 촬영·저장하지 않고 UI 계층으로 상태를 확인했다.
- 태블릿 시계는 변경하지 않았다. 자정 처리의 수정 검증은 자동 테스트로 수행했으며 실제 자정이 다시 지나는 실기기 대기 시험은 하지 않았다.
- 임시 화면 유지 설정은 기존 값 0으로 복원했다. 이번 한 번 카메라 허용도 취소하고 선택 플래그를 초기 요청 상태로 복원했다. 기기 통신·회전 설정은 이번 수정 검증에서 변경하지 않았다.

개발용 앱 버전은 0.3.0을 유지한다. 설치한 수정 APK SHA-256은 `45b05b731565d1125e032bada3884674e810dc85b14d825098a3884f37ef425d`다. 이전 실기기 QA의 APK와 구분한다. 변경은 로컬 작업 폴더와 태블릿에 반영했으며 원격 push는 하지 않았다.

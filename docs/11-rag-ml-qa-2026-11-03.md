# RAG·머신러닝 실기기 검증

검증일: 개발 PC 기준 2026-11-03. 대상은 연결된 Samsung SM-T735N, Android 13/API 33, ARM64, RAM 약 3.35 GiB이다. 기존 구현과 기본 JSON 모델은 이미 있었으며, 이번 작업에서 공개 임베딩 모델을 새 태블릿에 반입하고 실제 실행을 검증했다. 변경은 로컬 작업 폴더에 있으며 원격 push는 하지 않았다.

후속 검사에서 선택 요약 모델을 설치하고 실제 태블릿 요약 생성도 통과했다. 최신 설치 상태와 결과는 [태블릿 요약 실행](12-tablet-summary-qa-2026-11-03.md)을 따른다. 아래 미설치 표시는 이 검사 시점의 기록이다.

## 확인한 결과

| 검사 | 이번 실행 결과 |
| --- | --- |
| Flutter 전체 회귀 | 132개 통과, 실패 0 |
| 정적 분석 | 오류 0, 경고 0, 기존 info 3건 |
| 저장된 모델 Python↔Dart | 예측 3,600건·분류 861건 일치 |
| 같은 모델의 Android 실행 | 예측 3,600건 최대 절대 차이 3.33×10⁻¹⁶, 분류 861건 차이 0 |

| 오프라인 실행 | 비행기 모드와 Wi-Fi·데이터 차단 상태에서 두 진단 통과; 종료 후 기존 설정 복원 확인 |

검색 문서는 명시적으로 가상인 3개뿐이다. 따라서 top 5도 최대 3개이며 실제 대규모 문서의 검색 정확도나 정답 포함률을 증명하지 않는다. 검색 주기·절차·가혹조건 질문의 첫 근거가 각각 해당 가상 문서인지 확인했다. 가상의 교환주기는 실제 정비 지침으로 사용하지 않는다.

최종 RAG 단일 검색 관측 시간은 635.495 / 620.306 / 741.671 ms였다. 첫 모델 로드/추론/해제는 1,529.981 / 92.802 / 6.370 ms였다. 디버그 실행의 제한된 표본이며 제품 지연시간 보장이나 전체 앱 최대 메모리 측정이 아니다.

## 변경한 검증 경로와 데이터 보존

- `tools/evaluate_saved_models.py`: 기존 JSON 가중치를 재학습하지 않고 전체 합성 홀드아웃·미래·입력오차·시나리오를 재평가하고 PC/기기 비교 입력을 생성한다.
- `tools/model_holdout_parity_test.dart`: 전체 홀드아웃의 Python 기준 출력과 실제 Dart 계산을 비교한다.
- `tools/prepare_rag_qa_fixture.py`, `tools/prepare_rag_rankings_test.dart`: 원본 업무 자료 없이 가상 문서와 같은 앱 정렬기의 PC 기준 순위를 만든다.
- `lib/ml_device_probe.dart`, `lib/main.dart`: 명시적으로 호출하는 ML 진단 진입점을 추가했다. 일반 앱 화면에는 영향을 주지 않고 영구 업무 DB에 접근하지 않는다.
- Android 계측 진단은 진입점·실기기 여부·반입 여부를 기록한다. 실행별 UUID를 결과와 대조하여 이전 실행 결과를 새 성공으로 오인하지 않는다.
- `tools/run_rag_device_qa.py`: 오프라인 기기 실행, 결과 회수, 무선 설정 복원을 수행한다.

임베딩은 앱의 `files/rag/active`에 설치했다. 가상 지식은 진단용 메모리 DB에서만 사용했으며 업무 DB에 등록하지 않았다. 기존 업무 자료는 삭제하지 않았다. 선택형 실제 자료 분류 패키지(`.msystem`)와 요약 LLM(`.gguf` 및 실행 라이브러리)은 이 태블릿에 없어 이번 실기기 검증 대상에 포함하지 않았다. 과거 에뮬레이터 기록을 이번 실기기 결과로 바꾸지 않는다.

## 모델 성능의 한계

기본 예측 모델의 합성 홀드아웃 AUC 0.8841, F1 0.5146, 정밀도 0.5539, 재현율 0.4805를 재현했다. 양성 385건 중 185건을 탐지하고 200건을 놓쳤다. 정기 예방정비 시나리오의 양성 11건도 모두 놓쳤다. 미래 구간 F1은 0.5644, 입력오차 시험 F1은 0.3974였다. 실행 정합성 통과와 예측 성능은 다른 결과이다.

문장 분류는 정상 합성 861건에서 두 분류 모두 정확도 100%였고, 부속명 누락·문자 삭제 시험에서는 약 96.3%와 각 32건 보류였다. 실제 자유 문장 정확도를 뜻하지 않는다. 실제 등록 차량의 잔여 정비거리는 등록 규칙으로 계산하며 합성 차량용 고장 확률과 구분한다. 실제 업무 문서 검색 품질, 사람 검토 정답, 선택 LLM 요약 효용, 실제 자료 분류 파일럿은 별도 검증이 필요하다.

## 재현 경로

프로젝트 루트에서 Flutter·JDK·Android SDK·ONNX AAR 설정은 [환경 설정](00-workspace-setup.md)과 [태블릿 기록](08-tablet-qa-2026-11-03.md)을 따른다. 명령의 `flutter`, `python`, `adb`는 해당 환경의 실행 파일을 사용한다.

```sh
python tools/evaluate_saved_models.py --output output/model-qa
ML_QA_DIR=output/model-qa flutter test tools/model_holdout_parity_test.dart
python tools/prepare_rag_qa_fixture.py --output private/qa-rag
# 공개 가중치를 models/local/distiluse-int8에 준비한 후 실행
python tools/build_oil_embedding_bundle.py --source private/qa-rag/knowledge.json --output private/qa-rag/bundle
RAG_QA_DIR=private/qa-rag flutter test tools/prepare_rag_rankings_test.dart
```

번들 도구의 Python 의존성은 ONNX 1.19.1, ONNX Runtime 1.23.2, tokenizers 0.22.1, safetensors 0.6.2를 사용했다. 이번 가중치 출처는 [Xenova](https://huggingface.co/Xenova/distiluse-base-multilingual-cased-v2) revision `cad454171d918d9873a2701ba245054b6c1760dd`의 `onnx/model_quantized.onnx`·토크나이저와 [sentence-transformers](https://huggingface.co/sentence-transformers/distiluse-base-multilingual-cased-v2) revision `bfe45d0732ca50787611c0fe107ba278c7f3f889`의 `2_Dense/model.safetensors`이다. 모델은 Apache 2.0이며 라이선스도 함께 반입했다.

| 파일 | SHA-256 |
| --- | --- |
| 원본 model_quantized.onnx | `1724c10ba3b33b58afb6ce73bbf3e0528921bd4d4e1bf5a569b6d73f234e72bf` |
| dense.safetensors | `0a21b1ce908e772ebf09f93c20ca09524c32706e9918d9c0169a3f0663b191ed` |
| 병합 bundle/model.onnx | `239d513f2691ca5107646f5b36c5b2627eac5171adb8003669c2f6ee08a48598` |

앱 debug APK와 `app:assembleDebugAndroidTest -Ptarget-platform=android-arm64`로 만든 계측 APK를 설치한 후 아래 파일을 앱 전용 경로에 준비해야 한다. `run-as`는 debug 앱에서만 가능하다. 패키지는 `com.superkid.military.military_maintenance`이다.

| PC 생성물 | 앱 전용 위치 |
| --- | --- |
| private/qa-rag/oil-filter-int8.mrag | cache/maintenance-import-probe.mrag |
| private/qa-rag/parity-probes.json | files/rag-probes.json |
| private/qa-rag/pc-rankings.json | files/rag-pc-rankings.json |
| output/model-qa/device-probes.json | files/ml-qa-probes.json |

```sh
python tools/run_rag_device_qa.py --adb /path/to/adb --serial DEVICE_ID --entry ragDeviceProbe --output output/rag-device-qa
python tools/run_rag_device_qa.py --adb /path/to/adb --serial DEVICE_ID --entry mlDeviceProbe --output output/ml-device-qa
flutter test
flutter analyze
```

기기 실행은 앱을 강제 종료하고 무선 설정을 잠시 바꾸므로 진행 중인 입력을 저장한 뒤 실행한다. 파일을 준비하지 않은 새 기기에서는 성공하지 않는다. 이번에 사용한 가중치·색인·가상 입력·기기 로그는 Git에서 제외된 경로에 보관하며 공개 저장소에 추가하지 않는다.

# 모델 학습과 평가

## 모델과 선택 방법

| 과제 | 모델 | 입력 | 출력 |
| --- | --- | --- | --- |
| 다음 달 정비 발생 | L2 로지스틱 회귀 | 숫자 특성 14개 | 가상 고장수리 확률 |
| 정비 문장 분류 | 문자 2·3그램 다항 나이브 베이즈 | 부속명·정비 문장 | 계통 9종·예방/고장수리 |

PC의 Python·NumPy로 학습하고 JSON 매개변수를 Dart에서 계산합니다. 태블릿에 Python이나 모델 서버가 필요하지 않습니다.

숫자 모델은 정규화 강도 후보 4개를 각각 1,000회 학습했습니다. 학습에서만 평균·표준편차를 계산하고 검증 로그 손실로 후보를 선택했습니다. 검증 F1로 선택한 현재 임계값은 0.33이며 실제 정비 판단 기준은 아닙니다.

## 데이터 개선 이유

v2는 사건의 많은 부분이 확률 추첨이고 다음 달 운행량에 독립적인 난수가 들어가, 현재 정보로 예측할 수 없는 요소가 컸습니다.

v3는 운행 연속성과 상태 악화·회복을 도입했습니다. 내부 상태를 특성으로 직접 주지 않고 관측 기록에 나타나게 했습니다. 모델 복잡도보다 합성 과제의 시간 흐름을 개선한 것입니다.

## 숫자 예측

| 평가 | AUC | F1 | 정밀도 | 재현율 | 표본 |
| --- | ---: | ---: | ---: | ---: | ---: |
| v2 전체 시험 | 0.630 | 0.287 | 0.249 | 0.339 | 3,600 |
| v3 전체 시험 | 0.884 | 0.515 | 0.554 | 0.481 | 3,600 |
| v3 미학습 차량 미래 기간 | 0.884 | 0.564 | 0.590 | 0.541 | 675 |
| v3 입력 오차 | 0.814 | 0.397 | 0.338 | 0.483 | 3,600 |

상수 확률 기준선 AUC는 0.500입니다. 새 시험의 양성 비율은 약 10.7%여서 정확도만 보면 다수 음성 예측이 성능을 과장할 수 있습니다.

입력 오차 시험은 월 거리 ±15%, 유류량 ±10%를 변형하고 소모율을 다시 계산했습니다. 정답·임계값을 유지하고 재학습하지 않았습니다.

## 시나리오별 시험

| 시나리오 | AUC | F1 | 양성 |
| --- | ---: | ---: | ---: |
| 정기 예방정비 | 0.532 | 0.000 | 11 |
| 정비 지연 | 0.910 | 0.451 | 55 |
| 운행량 증가 | 0.868 | 0.558 | 63 |
| 반복 수리 | 0.841 | 0.472 | 115 |
| 저운행 | 0.832 | 0.240 | 35 |
| 고운행 | 0.892 | 0.638 | 106 |

정기 예방정비 차량의 드문 양성 11건을 모두 놓쳤습니다. 전체 사건도 약 절반만 탐지하므로 개별 사건을 충분히 맞힌다고 판단할 수 없습니다.

## 문장 분류

정상 합성 시험 861건에서 두 분류 모두 정확도 100%였습니다. 부속명 입력을 비우고 문장 글자를 일부 삭제하면 정확도 약 96.3%, 각 32건 보류였습니다. 보류를 정답으로 세지 않았습니다.

알려진 문자 수·어휘 커버리지·점수가 부족하면 보류하고, 제안이 나와도 사용자가 적용해야 저장값이 바뀝니다. 유한한 가상 표현의 결과이므로 실제 자유로운 문장 성능은 아닙니다.

## 해석의 한계

- v2/v3는 생성 규칙·정답 분포·학습 기간이 달라 같은 고정 벤치마크 비교가 아닙니다.
- 마모와 유류 소모의 관계는 인위적으로 만든 가정입니다.
- 실제 고장 라벨, 비전 판정·답변 생성 자료는 사용하지 않았습니다.
- 월말 학습과 월중 입력의 조건이 달라 부분월 정확도는 미검증입니다.
- 사용자 입력 보호로 남은 이전 합성 이력의 성능은 별도 검증 대상입니다.
